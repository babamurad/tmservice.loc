# Чек-лист продакшен-запуска

Не план разработки (это `01-backend.md`/`02-mobile.md`) — операционный
список того, что нужно сделать/проверить перед реальным запуском. Часть
пунктов техническая (код уже готов, нужна только конфигурация), часть —
организационная (аккаунты, юрлицо, домен), часть — то, чего в проекте
физически ещё нет и стоит решить, нужно ли оно для старта.

Статус `[x]`/`[ ]` означает «сделано»/«не сделано», не «легко»/«сложно».

---

## 1. Домен и хостинг

- [ ] Купить прод-домен. Один домен закрывает сразу два открытых пункта
  плана: `APP_URL` бэкенда и Universal Links (`plan/README.md`, Этап 4A/6).
  `tmservice.loc` — локальный псевдо-TLD OSPanel, для прода не годится.
- [ ] Выбрать хостинг с PHP 8.3+ (реальная версия на вашей машине —
  8.3.29, `composer.json` требует `^8.3`, `config.platform.php` в
  `composer.json` зафиксирован на `8.3.0`, чтобы `composer install`
  никогда не запинил пакет несовместимой версии — см. историю с
  `symfony/html-sanitizer`).
- [ ] Решить: SQLite (сейчас в dev/`.env.example`) или перейти на
  MySQL/PostgreSQL для прода. SQLite технически выдержит небольшую
  нагрузку одного города, но пишет через файловую блокировку — при
  одновременных запросах от мобильного API и админки может быть
  узким местом раньше, чем ожидается. Для такого масштаба (один город)
  решение не критично, но стоит сознательно принять, а не унаследовать
  по умолчанию.
- [ ] HTTPS с валидным сертификатом (Let's Encrypt и т.п.) — обязателен
  и для API (токены Sanctum), и для `apple-app-site-association`
  (Apple требует HTTPS для Universal Links).

## 2. Переменные окружения (`.env` на проде)

- [ ] `APP_ENV=production`, `APP_DEBUG=false` — **критично**: сейчас в
  `.env.example` `APP_DEBUG=true`, при `true` в проде Laravel отдаёт
  полный стектрейс с путями и данными на любой ошибке 500.
- [ ] `APP_KEY` — сгенерировать заново на проде (`php artisan key:generate
  --force`), никогда не переносить dev-ключ.
- [ ] `APP_URL=https://<домен>`.
- [ ] `DB_*` — реальные прод-креды.
- [ ] `SMS_GATEWAY`, `VONAGE_*`/`TWILIO_*` — заполнить, когда будет
  доступ к API оператора (см. `plan/sms-gateway-spike.md`). До тех пор
  `SMS_GATEWAY=log` — безопасный дефолт, ничего никуда не уходит.
- [ ] `APPLE_APP_BUNDLE_ID`, `APPLE_TEAM_ID`, `ANDROID_PACKAGE_NAME`,
  `ANDROID_SHA256_CERT_FINGERPRINTS`, `APP_STORE_URL`, `PLAY_STORE_URL`
  — заполнить после публикации приложения в сторах (см. раздел 6).
- [ ] `FILESYSTEM_DISK` — см. раздел 4, решить локальный диск или S3
  (`AWS_*` переменные уже есть в `.env.example`, просто не заполнены).
- [ ] Убедиться, что `.env` не попадёт в git (уже в `.gitignore`, но
  стоит перепроверить на самом хостинге при первом деплое).

## 3. База данных и данные

- [ ] `php artisan migrate --force` (не `migrate:fresh` — это стирает
  всё). `DemoDataSeeder` не выполнится сам — он привязан к
  `app()->environment(['local', 'testing'])`, на `APP_ENV=production` не
  запустится ни при `migrate --seed`, ни отдельно.
- [ ] `CitySeeder`/`CategorySeeder` выполняются в проде безусловно
  (через `DatabaseSeeder`) — 5 городов и 4 категории появятся сами.
- [ ] Создать первого реального админа:
  `php artisan make:admin +993XXXXXXXXX` — это единственный способ
  получить роль `admin`, кроме сидера (см. `plan/01-backend.md`, П0).
  Задать ему пароль сильнее, чем демо-пароль `password`.
- [ ] `php artisan storage:link` — без этого ссылки на фото портфолио
  (`/storage/...`) будут отдавать 404.
- [ ] Добавить реальные посёлки-спутники Туркменабада через `/admin` →
  Города, если решили, какие нужны (см. `plan/README.md`, раздел про
  `parent_city_id` — демо-сидер добавляет только Фарап, и то не в проде).

## 4. Хранилище файлов и бэкапы

- [ ] Портфолио мастеров хранится на `FILESYSTEM_DISK=local` —
  физические файлы на диске сервера. Если хостинг эфемерный
  (контейнеры без персистентного диска, автоскейлинг) — файлы пропадут
  при пересборке. Тогда нужен S3-совместимый диск (переменные `AWS_*`
  уже в `.env.example`, `intervention/image-laravel` их не касается —
  переключение диска не требует правок кода, только `.env` +
  `config/filesystems.php`).
- [ ] Резервное копирование БД — ничего не настроено, нужно решить
  отдельно от кода (пример: `pg_dump`/`mysqldump` по расписанию, либо
  штатный бэкап хостинга).
- [ ] Если диск локальный — бэкапить и `storage/app/public`, не только
  БД, иначе бэкап без фото портфолио бесполезен при восстановлении.

## 5. Безопасность

- [ ] `APP_DEBUG=false` — продублировано из раздела 2 намеренно, это
  единственный пункт, ошибка в котором реально утекает данные наружу.
- [ ] Rate limiting уже в коде (`auth`, `otp`, `public-read` —
  `AppServiceProvider::boot()`) — сработает автоматически, отдельно
  включать не нужно, но стоит один раз проверить на проде `curl`-ом.
- [ ] `/admin` защищён `role=admin` (`User::canAccessPanel()`) — уже
  работает. Для лучшей защиты можно рассмотреть 2FA средствами Filament
  или ограничение по IP на уровне веб-сервера — не блокирует запуск,
  это усиление поверх готового.
- [ ] Нет восстановления пароля — ни в мобильном API, ни в Filament.
  Раздел «Пользователи» в `/admin` сейчас только на просмотр (сознательно,
  см. `plan/README.md` — регистрация только через приложение), сменить
  пароль забывшему его пользователю оттуда нельзя. Сейчас единственный
  путь — прямой доступ к БД. Стоит решить, насколько это критично для
  MVP с небольшим числом мастеров/клиентов на старте, или сразу строить
  эндпоинт восстановления.

## 6. Мобильное приложение

- [ ] Указать в `ServiceApp` реальный прод `APP_URL` вместо
  `localhost`/`tmservice.loc` в месте, откуда берётся адрес API
  (`src/api/client.js`).
- [ ] `eas.json` в проекте ещё нет — EAS Build не настроен. Нужен
  `eas build:configure` (Expo Application Services) перед первой сборкой
  под реальные App Store/Google Play.
- [ ] Apple Developer Program ($99/год, нужен аккаунт) — без него нет
  `APPLE_TEAM_ID`, нет публикации в App Store.
- [ ] Google Play Console ($25 разово) — без него нет публикации в Play.
- [ ] После первой прод-сборки — забрать `APPLE_TEAM_ID` и
  `ANDROID_SHA256_CERT_FINGERPRINTS` и вписать в `.env` бэкенда (раздел 2)
  — только тогда `apple-app-site-association`/`assetlinks.json` начнут
  отдавать реальные `details`, и Universal Links заработают без схемы.
- [ ] Иконки, скриншоты, описание для карточек в сторах — не
  готовились в рамках разработки, это отдельная (не техническая) задача.
- [ ] Политика конфиденциальности — публичная страница/URL, оба стора
  требуют её для публикации, в проекте её пока нет.
