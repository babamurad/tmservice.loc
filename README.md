# Найди мастера

Локальный сервис-справочник мастеров (сантехники, электрики, ремонт авто,
сборка мебели) для Туркменабада. Backend — Laravel API, клиент — мобильное
приложение на Expo/React Native. Веб есть только там, где это осознанное
исключение: QR-визитка мастера (`/m/{id}`) и админ-панель (Filament).

Полный план разработки, принятые архитектурные решения и статус по
этапам — в [`plan/README.md`](plan/README.md). Этот файл — только про то,
как поднять проект локально.

## Стек

**Backend**
- PHP 8.3+, Laravel 13, Sanctum (токены для мобильного API)
- SQLite (dev/test), Filament 5 (админ-панель, `/admin`)
- `endroid/qr-code` (QR-визитки), `intervention/image` (сжатие фото в webp)

**Мобильное приложение** (`ServiceApp/`)
- Expo SDK 56, React Native 0.85, React Navigation 7
- `@react-native-async-storage/async-storage` (офлайн-кэш справочников)

## Быстрый старт (backend)

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate:fresh --seed
php artisan storage:link
php artisan serve
```

`--seed` в `local`/`testing`-окружении дополнительно накатывает демо-данные
(`DemoDataSeeder`) — несколько мастеров, клиентов и отзывов, чтобы сразу
было с чем работать. Пароль у всех демо-аккаунтов: `password`.

| Роль | Телефон | Заметка |
|---|---|---|
| admin | `+993610000001` | вход в `/admin` |
| master | `+993610000010` | Сантехник, Туркменабад, свободен, есть отзыв |
| master | `+993610000011` | Электрик, Туркменабад, занят |
| master | `+993610000012` | Ремонт авто, Туркменабад, свободен, есть отзыв |
| master | `+993610000013` | Сборка мебели, Ашхабад, свободен |
| client | `+993610000020` | уже оставил отзыв мастеру #1 |
| client | `+993610000021` | уже оставил отзыв мастеру #3, может оставить ещё |

Админа вне сидера можно выдать только через
`php artisan make:admin {телефон}` — по дизайну роль `admin` нельзя
получить через обычную регистрацию (см. `plan/01-backend.md`, П0).

### Composer и GitHub-токен

Если `composer install` попросит GitHub-токен — это стандартный запрос
Composer к `api.github.com` за метаданными пакетов (лимит анонимных
запросов быстро кончается). Ни один пакет проекта не приватный, поэтому
достаточно fine-grained-токена без прав на репозитории (вариант 1 в
подсказке Composer). Подробности:
[Authentication for private packages](https://getcomposer.org/doc/articles/authentication-for-private-packages.md#github-oauth).

### Админ-панель

`/admin` — Filament, вход по номеру телефона (не email) и паролю, только
для `role = admin`. CRUD городов/категорий, модерация мастеров и отзывов
(вкладки «на модерации / одобрены / отклонены»), список пользователей.

## Мобильное приложение

```bash
cd ServiceApp
npm install
npm run web    # или: npm start — для Expo Go на телефоне
```

По умолчанию клиент ходит на `APP_URL` из backend `.env` — для локальной
разработки через OSPanel (или аналог) укажите реальный хост, доступный с
телефона/эмулятора, не `localhost`.

## Тесты

```bash
php artisan test
./vendor/bin/pint --test
```

У `ServiceApp` пока нет JS-тестовой инфраструктуры (нет `jest`,

## Известные ограничения

- **SMS не отправляются** — `LogSmsGateway` пишет OTP-код в лог, реального
  провайдера для `+993` ещё нет (кабинетный спайк — `plan/sms-gateway-spike.md`).
  Ручная модерация мастеров (Filament) сейчас работает как замена верификации.
- **Universal Links не активны** — нужен публичный прод-домен (пока не
  выбран); мобильная часть уже готова принять его без правки кода
  (`plan/02-mobile.md`, Этап 6). Диплинк на карточку мастера пока работает
  через кастомную схему `serviceapp://m/{id}`.
- **Посёлки-спутники Туркменабада** — решение принято (`parent_city_id` в
  `cities`, см. `plan/README.md`), но не реализовано.
